Processing library reference

        
      

      

        

          Everything below is opened by default — no open needed.
          Geometry is float, colour channels are int
          in 0–255, angles are radians.
        


        
Canvas

        
    
          
  • size : float -> float -> unit
    • 
          
  • width : unit -> float · height : unit -> float
    • 
          
  • background : ?a:int -> int -> int -> int -> unit
    • 
          
  • background_gray : ?a:int -> int -> unit
    • 
          
  • clear : unit -> unit
    • 
        


        
Style

        
    
          
  • fill : ?a:int -> int -> int -> int -> unit
    • 
          
  • fill_gray : ?a:int -> int -> unit
    • 
          
  • fill_hsb : ?a:int -> float -> float -> float -> unit h 0–360, s/b 0–100
    • 
          
  • no_fill : unit -> unit
    • 
          
  • stroke, stroke_gray, stroke_hsb, no_stroke
    • 
          
  • stroke_weight : float -> unit
    • 
          
  • stroke_cap : [`Round|`Square|`Project] -> unit
    • 
          
  • stroke_join : [`Miter|`Bevel|`Round] -> unit
    • 
          
  • rect_mode, ellipse_mode : [`Corner|`Corners|`Center|`Radius] -> unit
    • 
        


        
Shapes

        
    
          
  • point x y · line x1 y1 x2 y2
    • 
          
  • rect x y w h · square x y s · rect_rounded x y w h r
    • 
          
  • ellipse x y w h · circle x y d
    • 
          
  • arc x y w h start stop
    • 
          
  • triangle x1 y1 x2 y2 x3 y3
    • 
          
  • quad x1 y1 x2 y2 x3 y3 x4 y4
    • 
          
  • bezier x1 y1 cx1 cy1 cx2 cy2 x2 y2
    • 
          
  • begin_shape (), vertex x y, bezier_vertex ..., end_shape ?close ()
    • 
        


        
Transforms

        
    
          
  • push_matrix () / pop_matrix () (also save and restore the style)
    • 
          
  • translate x y · rotate a · scale s · scale_xy sx sy
    • 
          
  • reset_matrix ()
    • 
        


        
Text

        
    
          
  • text : string -> float -> float -> unit
    • 
          
  • text_size : float -> unit · text_font : string -> unit
    • 
          
  • text_align : ?v:[`Top|`Middle|`Baseline|`Bottom] -> [`Left|`Center|`Right] -> unit
    • 
          
  • text_width : string -> float
    • 
        


        
Loop & input

        
    
          
  • draw : (unit -> unit) -> unit runs every frame
    • 
          
  • no_loop () · loop () · frame_rate : float -> unit
    • 
          
  • frame_count : unit -> int · millis : unit -> float
    • 
          
  • mouse_x (), mouse_y (), pmouse_x (), pmouse_y ()
    • 
          
  • mouse_is_pressed (), key_is_pressed (), key_char (), key_code ()
    • 
          
  • mouse_pressed, mouse_released, mouse_moved, mouse_dragged, mouse_clicked, key_pressed, key_released — all take a (unit -> unit) callback
    • 
        


        
Maths

        
    
          
  • random : ?min:float -> float -> float · random_int lo hi · random_seed : int -> unit
    • 
          
  • noise : ?y:float -> ?z:float -> float -> float · noise_seed : int -> unit
    • 
          
  • map_range v lo1 hi1 lo2 hi2 · norm v lo hi · lerp a b t
    • 
          
  • dist x1 y1 x2 y2 · mag x y · constrain v lo hi · sq x
    • 
          
  • radians d · degrees r · pi · two_pi · half_pi
    •

          keeps its state between runs — only the canvas is reset.
